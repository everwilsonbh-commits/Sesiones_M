Desarrollo · Comprensión del problema

La campaña en todo el colegio

Cada persona reenvía el mensaje a 3 compañeros nuevos.

  1. ¿En qué ronda reciben el mensaje exactamente 729 personas?
  2. ¿En qué ronda se alcanza la meta de 2 000 personas?
  3. Si log₃ N = log₃ 27 + log₃ 9, ¿cuántas personas reciben el mensaje?

Comprendemos

  1. ¿Cuántas personas reciben el mensaje en las rondas 1, 2 y 3?
    3, 9 y 27: se multiplica por 3.
  2. ¿Puede la ronda ser 6,9?
    No: n es natural (1, 2, 3…).

Desarrollo · Formalización

Formalizamos

Logaritmo: logb N = x ⇔ bˣ = N, con b > 0, b ≠ 1 y N > 0.

Es la operación inversa de la potenciación: responde «¿en qué ronda?».

  • Producto: log(M·N) = log M + log N
  • Cociente: log(M/N) = log M − log N
  • Potencia: log Mᵏ = k·log M
  • Cambio de base: logb N = log N / log b

Ecuación logarítmica

  1. Escribir las condiciones de existencia.
  2. Aplicar propiedades.
  3. Usar la definición.
  4. Resolver la ecuación.
  5. Verificar y descartar.

Ejemplo: log₂ x + log₂(x − 2) = 3 → x(x − 2) = 8 → x = 4 (x = −2 se descarta).

«log₂ 8 + log₂ 4 = log₂ 12»

Falso: 3 + 2 = 5 = log₂ 32; la suma de logaritmos es el logaritmo del producto.
